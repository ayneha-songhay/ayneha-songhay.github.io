Pour les développeurs

Ajoutez l'écriture AYNEHA à votre propre application Android avec le AYNEHA Keyboard SDK, une bibliothèque libre écrite en Kotlin.

Trois façons de l'intégrer

  1. Le clavier dans votre écran : le clavier AYNEHA posé directement dans votre application, sans que l'utilisateur change de clavier système.
  2. La translittération : l'utilisateur tape en lettres latines sur son clavier habituel, le texte s'écrit en AYNEHA à la volée.
  3. Le clavier système : le clavier AYNEHA complet, comme clavier Android, à inclure dans votre projet.

Les modes 1 et 3 partagent la même disposition de touches. Les 98 caractères AYNEHA et leurs points de code sont fournis.

Installation

Le SDK est fourni en code source, comme module Gradle :ayneha-keyboard à inclure dans votre projet. Il peut aussi être compilé en bibliothèque .aar. Le mode d'emploi complet se trouve dans le dépôt.

Bon à savoir

  • Les caractères AYNEHA sont dans la zone d'usage privé Unicode, de U+10FF7C à U+10FFDD : chacun occupe deux unités UTF-16. Manipulez des points de code, jamais des caractères isolés.
  • Ces points de code sont « forts de gauche à droite » pour Android : pour un affichage de droite à gauche correct, il faut inverser l'ordre des caractères avant de les dessiner.
  • N'appliquez jamais de gras ni de souligné à l'AYNEHA : pour mettre en valeur, agrandissez le texte.
