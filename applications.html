AYNEHA School Nouveau

Apprendre à lire et à écrire l'AYNEHA, seul et à son rythme.

  • L'alphabet lettre par lettre, avec la prononciation, l'épellation et toutes les formes de chaque lettre
  • Les accents, le syllabaire et les chiffres, avec un convertisseur de nombres
  • Le tracé des lettres au doigt, noté de 0 à 3 étoiles
  • Six jeux de quiz et des exercices de lecture sur de vrais mots songhay vérifiés par l'auteur
  • Un atelier de transcription du latin vers l'AYNEHA, avec partage en image

Android 8 ou plus récent. Fonctionne sans connexion, ne demande aucune autorisation. Sans publicité, aucune donnée collectée.

AYNEHA Keyboard

Le clavier pour écrire en AYNEHA dans toutes les applications du téléphone.

  • Disposition de droite à gauche, avec les lettres, les symboles, un pavé numérique et les émojis
  • Appui long sur une lettre pour ses formes : double, muette, nasalisée, ouverte
  • Bouton Partager : le texte devient une image lisible par tous, même sans la police AYNEHA
  • Pseudo et horodatage facultatifs sur les images partagées, vibration réglable

Installer un fichier APK téléchargé ici

Sur Naabiga, l'installation se fait comme dans toute boutique. Si vous téléchargez le fichier APK depuis ce site, Android vous demande une autorisation la première fois.

  1. Touchez « Télécharger l'APK ici » et attendez la fin du téléchargement.
  2. Ouvrez le fichier depuis la notification ou le dossier Téléchargements.
  3. Si Android le demande, autorisez votre navigateur à installer des applications. Ce réglage peut être désactivé ensuite.
  4. Touchez « Installer ». Les mises à jour suivantes s'installent de la même façon, sans perdre vos réglages.

Pour les développeurs

Vous voulez ajouter l'AYNEHA à votre propre application ? Le AYNEHA Keyboard SDK est une bibliothèque Android en Kotlin qui propose trois façons de l'intégrer :

  • le clavier AYNEHA posé directement dans un écran de votre application ;
  • la translittération à la volée : l'utilisateur tape en latin, le texte s'affiche en AYNEHA ;
  • le clavier système complet, à inclure dans votre application.

Les 98 caractères AYNEHA et leurs points de code y sont fournis. Le code des applications AYNEHA est un logiciel libre (licence GNU GPL v3 ou ultérieure) et la police est sous licence SIL OFL 1.1.
