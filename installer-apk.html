Installer un fichier APK

Les applications AYNEHA se téléchargent sur ce site sous forme de fichier APK. La première fois, Android vous demande une autorisation.

  1. Sur la page de l'application, touchez « Télécharger l'APK ici » et attendez la fin du téléchargement.
  2. Ouvrez le fichier depuis la notification ou le dossier Téléchargements.
  3. Si Android le demande, autorisez votre navigateur à installer des applications. Vous pourrez désactiver ce réglage ensuite.
  4. Touchez « Installer ». Les mises à jour suivantes s'installent de la même façon, sans perdre vos réglages.

Télécharger en toute confiance

Téléchargez les applications AYNEHA uniquement depuis ce site. Un fichier APK venu d'ailleurs peut avoir été modifié.
