Les applications AYNEHA

Des applications Android gratuites, sans publicité, sans compte et sans collecte de données. Elles sont distribuées sur Naabiga, la boutique d'applications du Burkina Faso, et peuvent aussi se télécharger directement sur ce site : à vous de choisir.

Pour l'instant, les applications existent seulement pour Android. Il n'y a pas encore de version pour iPhone (iOS) : sur iPhone, utilisez les outils en ligne, qui marchent dans le navigateur.
