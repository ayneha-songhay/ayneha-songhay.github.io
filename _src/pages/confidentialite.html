Confidentialité

En bref : ce site ne collecte rien sur vous.

Le site

  • Aucun cookie, aucun traceur, aucune mesure d'audience, aucune publicité.
  • Les polices et les scripts sont hébergés sur le site lui-même : votre navigateur ne contacte aucun service tiers en affichant les pages.
  • Ce que vous écrivez dans le transcripteur, le clavier ou l'essai de la page d'accueil reste dans votre navigateur et n'est envoyé nulle part. Le transcripteur garde votre dernier texte dans le stockage de votre navigateur, pour le retrouver à votre prochaine visite ; « Tout effacer » le supprime.
  • Le site est hébergé par GitHub Pages, qui peut enregistrer des informations techniques de connexion (comme l'adresse IP) pour assurer le service et sa sécurité.
  • Les liens vers d'autres sites (Naabiga, Omniglot, réseaux sociaux, Google Drive) mènent à des services qui ont leurs propres règles.

Les applications

Les applications AYNEHA ne demandent aucun compte, n'affichent aucune publicité et ne contiennent aucun outil d'analyse. Elles fonctionnent sur votre appareil, sans serveur. Rien de ce que vous tapez n'est enregistré ni envoyé. Le partage en image crée une image temporaire, seulement pour l'application que vous choisissez. Chaque application présente sa propre page de confidentialité.
