For developers

Add the AYNEHA writing system to your own Android app with the AYNEHA Keyboard SDK, a free library written in Kotlin.

Three ways to integrate it

  1. The keyboard in your screen: the AYNEHA keyboard placed directly in your app, without the user switching system keyboards.
  2. Transliteration: the user types in Latin letters on their usual keyboard, and the text is written in AYNEHA on the fly.
  3. The system keyboard: the complete AYNEHA keyboard, usable in every app, to include in your project.

Modes 1 and 3 share the same key layout. The 98 AYNEHA characters and their code points are provided.

Installation

The SDK is provided as source code, as a Gradle module :ayneha-keyboard to include in your project. It can also be built as an .aar library. The full instructions are in the repository.

Good to know

  • AYNEHA characters are in the Unicode Private Use Area, from U+10FF7C to U+10FFDD: each one takes two UTF-16 code units. Work with code points, never with isolated chars.
  • For Android, these code points are "strong left-to-right": for correct right-to-left display, reverse the order of the characters before drawing them.
  • Never apply bold or underline to AYNEHA: to emphasise, make the text larger.
